Create a vault

Encrypt a secret, split it into guardian-held shares, and define the threshold that unlocks recovery.

The server stores only a hash (commitment) of each share — never the share itself. Each guardian's share is delivered exactly once and removed from storage the first time it is viewed. If a guardian loses it, it is gone for good.

2 · Expiry & dead man's switch

If the owner does not renew before this deadline, the vault automatically enters recovery mode (dead man's switch). This protects the secret even if the owner is gone.
