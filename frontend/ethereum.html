Ethereum DEMO

Optional integration with Ethereum (Ganache) and Hyperledger Fabric. Both are demonstrations and clearly labeled as such — the core product runs on the local simulated blockchain.

Truth in labeling: Ethereum contracts are compiled-ready Solidity source and connect to a local Ganache node only if it is running; they are not deployed to any public network. Hyperledger Fabric is an in-process JavaScript simulation (no real Fabric network required).
